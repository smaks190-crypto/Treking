# PulseHabit — Интерактивный Android-трекер привычек с Firebase

Создание нативного Android-приложения для отслеживания ежедневных привычек на Jetpack Compose на основе веб-прототипа PulseHabit с неоновой dark-glassmorphism стилистикой, матрицей дней (Пн–Вс), алгоритмом расчета серий (стриков), интерактивными графиками прогресса и синхронизацией между устройствами через Firebase Firestore и Google Sign-In.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **Подтвержденные решения на основе ответов пользователя:**
> 1. **Платформа и стек**: Нативное приложение Android на **Kotlin + Jetpack Compose** (Material 3). Обеспечивает 60+ FPS, плавные анимации кривых Безье, глубокую интеграцию с системными жестами и инсетами экрана.
> 2. **Авторизация и облако**: **Google Sign-In** через Jetpack **Credential Manager** (`GetSignInWithGoogleOption`) в связке с **Firebase Firestore** и правилами безопасности (Zero-Trust Security Rules), изолирующими данные каждого пользователя.
> 3. **Аналитика и визуализация**: **Полный комплект интерактивных графиков** — нативное переключение между столбчатой диаграммой недели и плавной градиентной волновой кривой (Custom Canvas Bezier path), а также круговой индикатор прогресса фокусного дня.

### 1. Overview & Core Concept

- **Что делает приложение**: PulseHabit позволяет пользователю ставить цели на каждый день недели (Пн–Вс), отслеживать серии непрерывных выполнений (flame streaks с учетом истории до текущей недели), видеть динамику продуктивности в процентах, фильтровать привычки по категориям и синхронизировать данные на любых устройствах Android через личный Google-аккаунт.
- **Целевая аудитория**: Пользователи, стремящиеся к дисциплине, разработчики, спортсмены и творческие специалисты, ценящие визуальную эстетику киберпанка и высокую отзывчивость интерфейса.
- **Ключевая ценность**: Мгновенный отклик при отметке целей (в одно касание), наглядная матрица прогресса за всю неделю без скрытых переходов, устойчивость к оффлайну с автосинхронизацией через Firestore.

### 2. User Experience & Visual Design

#### Ключевые пользовательские сценарии (User Flows)
1. **Экран авторизации (Auth Gate)**: При первом запуске отображается стильный темный приветственный экран с описанием возможностей и кнопкой «Войти через Google».
2. **Главный дашборд**:
   - **Хедер**: Логотип с иконкой пульса, бейдж PRO, дата на русском языке («Понедельник, 14 октября • Фокус: Пятница») и кнопка добавления новой привычки.
   - **Селектор фокусного дня**: Интерактивная лента (Пн, Вт, Ср, Чт, Пт, Сб, Вс) с индикацией реального сегодняшнего дня календаря.
   - **4 KPI-метрики**:
     - *Цели дня* с динамическим круговым кольцом прогресса и мотивационной фразой.
     - *Лучшая серия подряд (Стрик)* с огненной анимацией и названием привычки.
     - *Продуктивность недели* (процент и общее число закрытых отметок).
     - *Идеальные дни* (число дней со 100% выполнением и сумма всех серий).
   - **Фокус-чеклист на день**: Быстрый список привычек на выбранный день с кнопкой «Отметить все» и бейджем оставшихся задач.
   - **Динамический график недели**: Переключатель «Столбцы / Волна». В режиме столбцов — интерактивные бары с градиентами; в режиме волны — плавная кривая Безье на Canvas с градиентной заливкой и интерактивными точками.
   - **Матрица недели (Пн–Вс)**: Горизонтально скроллируемая сетка со всеми днями недели, фильтрами категорий («Все», «Код и IT», «Творчество», «Саморазвитие», «Здоровье и спорт», «Дисциплина»), шкалой выполнения за неделю, стриком и удалением.
3. **Модальный диалог создания привычки**:
   - Поле названия (до 48 символов).
   - Выбор категории из выпадающего списка.
   - Стартовая база (серия до начала недели).
   - Интерактивная сетка выбора иконок (Код, Музыка, Книга, Гантель, Щит, Пламя, Терминал, Наушники, Мозг, Капли, Луна, Молния).
   - Сетка неоновых цветовых акцентов (Фиолетовый, Циан, Изумруд, Розовый, Янтарный, Синий).

#### Визуальная айдентика и тема
- **Эстетика**: Cyberpunk Dark Glassmorphism — глубокий космический фон `#090D16` с тонкими неоновыми свечениями, полупрозрачные карточки (`rgba(17, 24, 39, 0.75)` / `bgCard`) с тонкими границами `borderDark` (`#1F2937`).
- **Цветовая палитра**:
  - `Violet`: `#8B5CF6` (основной акцент, кнопки действий)
  - `Cyan`: `#06B6D4` (вторичный неоновый акцент, графики, кольца прогресса)
  - `Emerald`: `#10B981` (продуктивность, идеальные дни)
  - `Orange / Amber`: `#F97316` / `#F59E0B` (пламя стрика)
  - `Rose`: `#F43F5E` (дисциплина, деструктивные действия)
- **Типографика**: Моноширинный шрифт для цифр и процентов (JetBrains Mono стиль), четкий гротеск для заголовков и категорий.

### 3. Key Product Decisions & Trade-Offs

- **Выбор Jetpack Compose против WebView**:
  - *Решение*: Полная переработка логики и верстки в нативные декларативные компоненты Compose.
  - *Причина*: Высокая плавность отрисовки (Hardware-accelerated Canvas для графиков), надежная работа с `CredentialManager` на Android 14–16, отсутствие оверхенда браузерного движка.
- **Хранение данных в Firestore**:
  - *Решение*: Коллекция `users/{userId}/habits/{habitId}` с real-time flow (`snapshots()`).
  - *Причина*: Изоляция данных на уровне пользователя, соблюдение строгих правил безопасности, оффлайн-кэширование Firestore из коробки.
- **Кастомная отрисовка графика через Compose `Canvas`**:
  - *Решение*: Построение кривых Безье `Path.cubicTo()` с градиентными кистями `Brush.verticalGradient` и `Brush.horizontalGradient`.
  - *Причина*: Идентичность веб-прототипу SVG, адаптивность под любые размеры экранов и плотности пикселей без подключения тяжелых сторонних библиотек.

#### Модель данных (Data Model)

```kotlin
data class Habit(
    @DocumentId val id: String = "",
    val userId: String = "",
    val title: String = "",
    val category: String = "Код и IT",
    val icon: String = "code",
    val color: String = "violet",
    val priorStreak: Int = 0,
    val week: List<Boolean> = listOf(false, false, false, false, false, false, false),
    @ServerTimestamp val createdAt: Timestamp? = null,
    @ServerTimestamp val updatedAt: Timestamp? = null
)
```

#### Расчет серий (Streak Algorithm)
- Считается непрерывный ряд отметок `week[d] == true` от активного дня назад до понедельника.
- Если на текущий активный день отметка еще не стоит, стрик берется со вчерашнего дня.
- Если непрерывная цепочка доходит до понедельника включительно, к результату прибавляется `priorStreak`.

### План выполнения (Execution Phases)

1. **Фаза 1: Подготовка конфигурации и зависимостей**
   - Проверка и раскомментирование необходимых Firebase-зависимостей в `app/build.gradle.kts` (`firebase.firestore`, `firebase.auth`, `credentials`, `credentials.play.services`, `googleid`).
   - Настройка `metadata.json` и `strings.xml` (название приложения **PulseHabit**).
2. **Фаза 2: Настройка Firebase & Security Rules**
   - Проведение рукопожатия `set_up_firebase` / `ProvisionFirebase` (SHA-1/SHA-256).
   - Создание `firebase-blueprint.json` и `firestore.rules` с защитой доступа по `request.auth.uid == userId`.
   - Развертывание правил безопасности через инструмент `deploy_firebase` / `DeployRules`.
3. **Фаза 3: Аутентификация и репозиторий данных**
   - Реализация Google Sign-In через Credential Manager с интерактивной кнопкой и обработкой отмен.
   - Создание `HabitRepository` с real-time потоком данных `observeHabits()` и методами переключения дней.
4. **Фаза 4: Пользовательский интерфейс и графика (Jetpack Compose)**
   - Оформление неоновой палитры в `Color.kt` и `Theme.kt`.
   - Компонент 4 KPI-карточек с анимированным круговым кольцом.
   - Интерактивный фокус-чеклист на выбранный день.
   - Компонент графиков: переключение между столбчатой гистограммой и гладкой волной Безье на `Canvas`.
   - Полная матрица недели с фильтрацией категорий.
   - Модальный диалог создания новой привычки с палитрой неоновых цветов и иконками.
5. **Фаза 5: Верификация и сборка**
   - Проверка через `compile_applet` и устранение возможных ошибок компиляции.
